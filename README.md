# 🥔 Potato Disease Detection (YOLOv8n + Render + GitHub Pages)

This project detects potato leaf diseases using a YOLOv8n classification model.

Classes supported:
- Potato___healthy
- Potato___Early_blight
- Potato___Late_blight

✅ Backend: Flask + YOLOv8 (Render Web Service)  
✅ Frontend: HTML/CSS/JS (GitHub Pages)
